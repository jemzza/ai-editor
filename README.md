# AI Editor для iPhone

Запуск: двойной клик по `Build.command` в Finder. Скрипт сам установит XcodeGen
(если его нет), сгенерирует проект, соберёт его и запустит в симуляторе. Если macOS
не даёт открыть файл — правый клик → «Открыть».

Нужен Xcode 26 (собирается с минимальной iOS 18).

## AI в приложении

Groq, OpenAI-совместимый `/chat/completions` со стримингом, модель
`openai/gpt-oss-120b` (`reasoning_effort: low`, без рассуждений в ответе).
Модель задаётся одной константой — `LLMConfig.model` в
[`AIEditor/Data/LLM/LLMConfig.swift`](AIEditor/Data/LLM/LLMConfig.swift); запасная —
`openai/gpt-oss-20b`. Ключ лежит в проекте обфусцированным
(`AIEditor/Data/Secrets/Secrets.generated.swift`, XOR с солью). Лимиты бесплатного тарифа
и расчёт на ~40 проверочных запросов — `docs/task.md`, «Решения».

## Подготовлено до старта

Шаблон собран из моего первого тестового (AI-чат); перенесено и переименовано Chat → Edit,
с тестами:

- XcodeGen-проект, `Build.command`, `scripts/` (свой симулятор на ветку, генерация ключа,
  синхронизация String Catalog, экспорт логов);
- Groq-клиент со стримингом (SSE), маппинг ошибок (нет сети / 429 / 401 / 403 / 5xx);
- GRDB: история правок и папки, контрактные тесты на in-memory и GRDB;
- `EditService`: стриминг с записью в БД ≤ 2 раз/с, Stop с сохранением частичного результата,
  Retry, `interrupted` после перезапуска, уведомление «Edit is ready»;
- сайдбар истории (поиск, даты, папки, drag-and-drop, переименование/удаление),
  настройки (уведомления, приватность, тема), диктовка и озвучка, общие UI-компоненты.

Новое для редактора до старта было только контрактами и заглушками: `PromptBuilding`,
`WordDiffing`, экран Editor. Подробно — `docs/plan.md`, «Подготовлено до старта».
