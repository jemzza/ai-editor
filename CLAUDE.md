@AGENTS.md

## Только для Claude Code

- Крупные шаги (экран целиком, слияние веток, изменение схемы БД, связка в `AppContainer`) —
  сначала в режиме плана; код — после согласия пользователя.
- Ревью перед слиянием — субагентом с чистым контекстом (Agent / `/code-review`), без истории
  этой сессии: ему — дифф ветки, `AGENTS.md` и нужные разделы `docs/`.
- Между этапами плана — `/clear`: контекст восстанавливается из `AGENTS.md` и `docs/`.
